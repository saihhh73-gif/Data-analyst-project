# 🛒 E-Commerce Sales Analysis & Dashboard

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to uncover
insights related to revenue, customer behavior, and product performance.

The goal is to transform raw data into meaningful insights and support
data-driven decision making.

------------------------------------------------------------------------

## 🎯 Objectives

-   Analyze sales performance across categories and regions\
-   Identify top-performing products and states\
-   Understand customer behavior and trends\
-   Build an interactive dashboard for insights

------------------------------------------------------------------------

## 🛠️ Tools & Technologies

-   Python (Pandas, NumPy)
-   SQL
-   Power BI
-   Excel (optional)

------------------------------------------------------------------------

## 📂 Dataset

-   Contains 30,000+ transaction records\
-   Includes:
    -   Order details\
    -   Product category\
    -   Revenue\
    -   Quantity\
    -   State\
    -   Date

------------------------------------------------------------------------

## 🔄 Data Processing

-   Data cleaning and handling missing values\
-   Feature engineering (Month, Year, etc.)\
-   Data transformation for analysis

------------------------------------------------------------------------

## 🧠 SQL Analysis

-   Total Revenue, Orders, Quantity\
-   Revenue by State\
-   Orders by Category\
-   Sales Channel Performance\
-   Customer Segmentation

------------------------------------------------------------------------

## 📊 Dashboard Features

-   KPI Metrics (Revenue, Orders, Quantity)\
-   Revenue by State\
-   Orders by Category\
-   Orders by Age Group\
-   Monthly Sales Trends

------------------------------------------------------------------------

## 📈 Key Insights

-   Certain states contribute significantly higher revenue\
-   Top categories drive majority of sales\
-   Amazon & Flipkart dominate order volume\
-   Sales show seasonal trends

------------------------------------------------------------------------

## 💡 Recommendations

-   Focus on high-performing categories\
-   Invest more in top sales channels\
-   Improve low-performing regions\
-   Use seasonal trends for planning
